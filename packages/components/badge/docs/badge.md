# Badge

> Added in v0.1.0-beta.0 | Stable since v0.1.0

Badge component for labels, status, and counts. Supports variants, colors, sizes, radius, and start/end content.

## Recent Changes

### v0.1.0-beta.0
- Initial beta release with five variants (solid, bordered, light, shadow, dot), six colors, three sizes, three radius options, disabled state, and start/end content slots.
