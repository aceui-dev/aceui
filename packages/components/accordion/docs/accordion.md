# Accordion

> Added in v0.1.0-beta.0 | Stable since v0.1.0

A flexible, accessible accordion for expanding and collapsing content sections. Supports single or multiple expansion, light/bordered/splitted variants, optional subtitles and start content, custom indicators, and default/lazy render strategies.

## Recent Changes

### v0.1.0-beta.0
- Initial beta release with single/multiple modes, variants (light, bordered, splitted), defaultExpandedKeys, disabledKeys, startContent, custom indicator, and lazy render strategy.
